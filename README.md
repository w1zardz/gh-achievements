# sandbox

Scratch repository for testing git and GitHub CLI workflows.

Used to exercise things I do not want to try on real projects:

- branch → PR → merge cycles and what each merge strategy does to history
- `gh` CLI automation (`gh pr create`, `gh pr merge`, `gh api graphql`)
- commit trailers, co-authorship, and how they survive squash vs merge commits
- Discussions API: creating threads, posting answers, marking an answer accepted

Contents are throwaway. `log.txt` is an append-only dummy file that exists
only to give each pull request something to change.

Nothing here is a real project. Do not depend on it.
